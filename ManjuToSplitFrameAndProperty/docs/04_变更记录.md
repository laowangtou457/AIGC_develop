## 2026-09-18 ｜ v1.1.0 ｜ 提示词结构对齐 MiniMax 官方 h3-prompt-writing 规范

### 背景
用户提供官方规范链接（MiniMax-AI/MiniMax-H3 → skills/h3-prompt-writing），
核实后确认官方按输入模式分两套结构：Ref2VA（全参考）= 六段式、I2VA（首帧）= 三字段。
本工程 reference 模式原本对齐社区规则（ComfyUI-H3-Prompt-Builder），结构名一致但细节不足；
i2v 模式原用六段式，与官方 I2VA 三字段结构不符。本次全部对齐。

### 变更（pipeline/h3_export.py）
| 项 | 变更 | 官方依据 |
|---|---|---|
| 段落常量 | `SECTIONS` 拆为 `REF_SECTIONS`（六段）与 `I2V_SECTIONS`（三字段），SECTIONS 保留兼容 | ref-en.txt §1 / base-en.txt §2.2 |
| `build_h3_prompt` | 改为模式分发器（reference→Ref2VA / i2v→I2VA），新增 `build_h3_prompt_ref` 与 `build_h3_prompt_i2v` | — |
| 标签体系 | 新增 `<Subject N>`（可复用内容，角色/场景）+ 保留 `<Picture N>`（图片锚点），subject_definitions 按官方句式定义 | ref-en.txt §2 |
| retention 档位 | 由配置 `h3.retention_level` 控制（4 档），不再硬编码 fully_preserved | ref-en.txt §4.1 |
| summary 任务类型 | 由配置 `h3.task_type` 控制（官方 6 类可组合） | ref-en.txt §3 |
| 时间戳 | 首镜无时间戳，后续镜头 `At MM:SS.mmm, the shot cuts to ...`（新增 `_fmt_timestamp`） | base-en.txt §4.2 / ref-en.txt §5.1 |
| 说话人 | 全局顺序分配 `(S1)(S2)...`（build_h3_pack 注入 speaker_ids），跨镜头复用 | base-en.txt §4.4 |
| 台词 | `<d>[中文/English] 原文</d>` 语言自动检测（`_detect_lang`）；标点规范化（`_clean_dialogue`） | ref-en.txt §5.4 |
| 正文句式 | 结构词英文（官方固定句式），内容字段保留 VLM 原文，对白原文保留 | ref-en.txt §Output Rules |
| i2v 结构 | 改为 Part One 首帧对齐指令 + 三字段 | base-en.txt §2.1/§2.2 |
| prompts.md | 标题按模式标注「Ref2VA 六段式 / I2VA 三字段」 | — |

### 新增功能
- **MiniMax H3 导出**（`pipeline/h3_export.py`）：
  - 六段式提示词（subject_definitions/summary/retention_analysis/detailed_description/overall_soundscape/non_diegetic_music）
  - 两种模式：reference（多模态参考生视频，角色/场景=reference_image）与 i2v（首帧图生视频）
  - 逐镜 API payload（POST /v2/video_generation 结构）、assets_manifest、mapping、validation_report（合规校验）
  - CLI：`python -m pipeline.h3_export <视频> [--mode reference|i2v]`
- **H3 提交工具**（`tools/submit_minimax_h3.py`）：payload → base64 data URL → POST → 轮询 → 结果落盘。
- **ComfyUI 集成**（`pipeline/comfyui_nodes.py` + `comfyui/__init__.py` + `workflows/manju_splitframe_workflow.json`）：
  - 5 个节点（SplitFrameParse / Structurize / AssetExtract / FullPipeline / H3Export），分类 "MiniMax H3 / 漫剧 / 抽帧与属性"
  - ManjuH3Export 为纯 JSON 进出节点（内存计算，可对接任意上游 JSON 分镜）
- **config.yaml**：新增 `generate.platform: minimax_h3` 与整个 `h3:` 段。
