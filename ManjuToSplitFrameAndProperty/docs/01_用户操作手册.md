## 3. 常用参数速查

| 参数 | 说明 | 默认 |
|---|---|---|
| `--asr-model off` | 关闭台词转录（视频无对白时用，省时） | tiny |
| `--asr-model base/small` | 提升转录准确率（更慢） | tiny |
| `--platform minimax_h3` | 导出 MiniMax H3 提示词 + payload | minimax_h3 |
| `--platform seedance/kling/veo/jimeng` | 导出对应平台通用提示词 | minimax_h3 |
| `--vlm-provider dashscope` | 开启画面理解（需 `DASHSCOPE_API_KEY`），自动写场景/动作/机位描述 | 关 |
| `--skip 1 --skip 2` | 跳过指定阶段（复用上次结果） | - |

示例（完整配置 + 跳阶段）：

```powershell
.\.venv\Scripts\python run_all.py "my.mp4" --asr-model small --vlm-provider dashscope --platform minimax_h3
.\.venv\Scripts\python run_all.py "my.mp4" --skip 1 --skip 2 --platform kling   # 只重做阶段3-4
```

## 4. 读懂产物

```
output\my_video\
├── video_info.json          # 视频元信息
├── shots.json               # 镜头表：哪个时间段是一个镜头
├── keyframes\               # 每个镜头的关键帧图片（挑片用）
├── storyboard.json          # 分镜表：镜头 + 台词 + 画面描述（文本，可改）
├── assets.json              # 资产清单：角色裁片 / 场景图（文本，可改）
├── assets\faces\            # 角色人脸裁片
├── assets\scenes\           # 场景代表帧
├── prompt_pack.md           # 通用平台提示词（seedance/kling/veo/jimeng 用）
└── minimax_h3\              # MiniMax H3 专用包 ★
    ├── prompts.md           # 六段式逐镜提示词 → 复制到海螺/API
    ├── payloads\shot_001.json  # 逐镜请求体 → 直接 POST
    ├── assets_manifest.json # 资产↔图N 映射
    └── validation_report.json  # 资产合规校验结果
```

### 4.1 资产替换的用法（核心玩法）

1. 打开 `minimax_h3\prompts.md`，看到 `subject_definitions: <Picture 1> is 角色0...`。
2. 想换角色：把 `<Picture 1>` 对应的 `assets\faces\shot_000_t000.0_f0.jpg` 换成你自己的形象图
   （如 3D 扫描脸型、原创角色立绘），提示词里把角色描述改成新形象。
3. 想换服装/场景：同理替换场景图并改提示词描述。
4. 台词要改：改 `detailed_description` 里 `<d>[中文] 原文</d>` 部分。
5. 提交生成，得到"剧情结构、台词、音乐氛围与原片接近，但人物形象、场景、服装全部替换"的原创片。

### 4.2 合规自检（每次发布前）

`prompts.md` 末尾的清单逐项确认：

- [ ] 输入视频是我自有 / 已授权 / 公有领域内容
- [ ] 剧情、台词、音乐已实质性改写（未逐帧复刻）
- [ ] 人物形象已替换为无版权问题形象（原创/授权/自扫描）
- [ ] 生成结果仅用于个人学习或非盈利展示

## 5. 提交 MiniMax H3 生成成片

### 5.1 方式 A：网页/客户端手动提交（推荐新手）

1. 打开 MiniMax 海螺（hailuoai.com）或 MiniMax 开放平台。
2. 图生视频 / 多模态生成入口，选择对应画幅与时长。
3. 上传资产图（角色/场景），粘贴 `prompts.md` 对应镜头的提示词。
4. 生成后检查一致性，必要时调 `retention_analysis` 的保留程度描述。

### 5.2 方式 B：API 一键提交（推荐批量）

```powershell
$env:MINIMAX_API_KEY = "你的Key"
.\.venv\Scripts\python tools\submit_minimax_h3.py "output\my_video\minimax_h3\payloads" --poll
```

- 自动把 payload 里的本地图片转成 base64 上传（单图 ≤30MB、请求体 ≤64MB）。
- `--poll` 会每 10 秒查一次任务状态，成功后返回成片 URL。
- 结果写入 `output\my_video\minimax_h3\submit_results.json`。

**提交前先看校验报告**：

```powershell
Get-Content "output\my_video\minimax_h3\validation_report.json"
# 每个资产 id 的值应为 []（通过）；有内容=警告，先修正
```

### 5.3 模式切换（config.yaml）

```yaml
h3:
  mode: reference   # reference=多模态参考生视频（默认）；i2v=首帧图生视频
  duration_auto: true   # true=按镜头时长自动夹取[4,15]秒；false=固定 duration_seconds
  audio_text_policy: 禁字幕+无BGM
```

## 6. 常见问题（FAQ）

| 问题 | 处理 |
|---|---|
| 报 `scenedetect` 或 `cv2` 错误 | 按第1节重装两个固定版本包 |
| 只切出 1 个镜头（视频明明有转场） | 合成/动画片转场弱，改低 `parse.scene_threshold`（20）或升级 TransNetV2（路线图） |
| 没检出角色 | Haar 对正脸敏感；把 `assets.min_face_size` 调小（40），或人工在 assets.json 补角色 |
| ASR 很慢 | 用 `--asr-model off` 或换 base；首次运行会下载模型（约 75MB） |
| 画面描述是"待补充" | 需要开启 `--vlm-provider dashscope`（配 DASHSCOPE_API_KEY） |
| H3 提示词太长被拒 | 检查 `detailed_description` 台词是否过长；提示词 ≤7000 字符 |
| 提交 413/图片超限 | 见 `docs/03_MiniMaxH3导出规范.md` 第4节限制表，先压图再传 |
