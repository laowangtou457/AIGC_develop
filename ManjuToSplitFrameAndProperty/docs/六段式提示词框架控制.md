## 3. 官方两套结构（修改前必读）

### 3.1 reference 模式 → Ref2VA 六段式（`docs/references/ref-en.txt`）

```
subject_definitions:   <Subject N> 定义 + <Picture N> 来源
summary:               [任务类型] 一句话概括
retention_analysis:    <Subject N> (appears in [Shot N]): <保留档位> - ...
detailed_description:  风格开场 + [Shot N]（后续 At MM:SS.mmm）+ 主体/机位/动作/光线 + 对白 + 字幕禁令
overall_soundscape:    环境音 1-4 句（不重复对白/音乐）
non_diegetic_music:    配乐 1-3 句（禁抽象情绪词）
```

### 3.2 i2v 模式 → I2VA 三字段（`docs/references/base-en.txt`）

```
For the target video, at 0.00 seconds into the target video, <Picture 1> (from [Shot 1]) is fully referenced.
（空行）
integrated_multimodal_description: [Shot N] ...
overall_soundscape: ...
non_diegetic_music: ...
```

### 3.3 关键规则（两套共用）

| 规则 | 官方要求 | 工程实现 |
|---|---|---|
| 时间戳 | 首镜无时间戳，后续 `At MM:SS.mmm, the shot cuts to ...` | `_fmt_timestamp` + 首镜分支 |
| 镜头运动 | 运动类型 + 幅度 + 速度自然成句 | 目前直接嵌入 `visual.camera` 原文（VLM 产出）；如需结构化再扩展 |
| 说话人 | `(S1)(S2)...` 按发声顺序全局分配、跨镜头复用；`(S1,S2)` 复合 | `build_h3_pack` 全局计数器注入 `speaker_ids` |
| 对白 | `<d>[语言] 原文</d>` 逐字保留；标点规范化；`[unclear]` 听不清 | `_detect_lang` + `_clean_dialogue` |
| 跨镜头台词 | `<scenetrans>` / `<cutoff>` | 未实现（ASR 无 speaker 分离，后续扩展点） |
| 保留档位 | fully_preserved / partially_preserved / attribute_transfer / weak_reference | `config.yaml → h3.retention_level` |
| 任务类型 | 6 类可 `+` 组合 | `config.yaml → h3.task_type` |

## 4. 各函数修改注意事项

### 4.1 `build_h3_prompt()`（114-122 行）——模式分发器

```python
def build_h3_prompt(shot, tags, cfg, mode="reference", speaker_ids=None) -> str:
    if mode == "i2v":
        return build_h3_prompt_i2v(shot, cfg, speaker_ids)
    return build_h3_prompt_ref(shot, tags, cfg, speaker_ids)
```

**注意事项**
- 新增生成模式（如未来加 FL2VA/L2VA）在此加分支，并同步 `main()` 的 `--mode` choices 与 `build_shot_payload` 的 role 逻辑。
- `tags` 在 i2v 模式下**不参与**提示词（I2VA 只引用首帧 `<Picture 1>`），函数签名保留 tags 仅为统一接口。

### 4.2 `build_h3_prompt_ref()`（149-236 行）——★ Ref2VA 六段式

```python
def build_h3_prompt_ref(shot, tags, cfg, speaker_ids=None) -> str:
    v = shot.get("visual") or {}
    shot_no = shot["id"] + 1
    dur_s = _shot_duration(shot, cfg)
    ar = cfg.get("ratio", "9:16")
    no_bgm, no_sub = _policy_flags(cfg.get("audio_text_policy", ""))
    retention = cfg.get("retention_level", "fully_preserved")  # 官方 4 档
    task_type = cfg.get("task_type", "reference generation")   # 官方 6 类可组合
```

**第 1 段 subject_definitions**（155-169 行）：

```python
    lines.append("subject_definitions:")
    for t in tags:
        if t.get("kind") == "scene":
            lines.append(f"{t['subject']} is the environment {scene_desc()}, "
                         f"whose appearance comes from {t['tag']}.")
        else:
            desc = t["desc"] or t["name"]
            lines.append(f"{t['subject']} is the character {t['name']} ({desc}), "
                         f"whose appearance comes from {t['tag']}.")
    if not tags:
        lines.append("No reference assets for this shot; describe the scene purely from text.")
```

- `t["subject"]`（`<Subject N>`）与 `t["tag"]`（`<Picture N>`）的编号**在 `build_h3_pack` 生成**，这里只消费——**不要在此改编号**，否则提示词与 payload 图片错位。
- 想给角色加详细外观特征（如"长发、蓝毛衣"），扩展 `t["desc"]` 的来源（`_char_desc` / VLM characters 字段）。

**第 2 段 summary**（171-180 行）：

```python
    chars = "、".join(t["name"] for t in tags if t.get("kind") != "scene" and t["role"].startswith("c"))
    subject = chars or "the subject"
    lines.append("summary:")
    lines.append(f"[{task_type}] The target video shows {subject} in {scene_desc()}, "
                 f"{v.get('action') or 'with the action described below'}, "
                 f"lasting {dur_s} seconds at {ar} aspect.")
```

- `task_type` 来自配置；官方 6 类：keyframe completion / reference generation / video editing / video continuation / audio reuse / audio reference，可写 `"video editing + audio reuse"` 组合。
- `role.startswith("c")` 依赖角色 id 以 `c` 开头（stage3 约定），改 id 命名规则需同步。

**第 3 段 retention_analysis**（183-191 行）：

```python
    lines.append("retention_analysis:")
    for t in tags:
        label = t["name"] if t.get("kind") != "scene" else scene_desc()
        lines.append(f"{t['subject']} (appears in [Shot {shot_no}]): {retention} - "
                     f"the {label} keeps the appearance and consistency defined in subject_definitions.")
```

- `retention` 由配置控制——**换装/换景玩法改 `config.yaml → h3.retention_level` 即可**，不用改代码。
- 官方不允许在 retention_analysis 里写 `(Sx)`（§5.4），保持现状。

**第 4 段 detailed_description**（194-223 行）——最长段，逐句注意：

```python
    style = cfg.get("style", "写实电影质感")
    opener = f"The target video is in {style} style."
    shot_start = float(shot.get("start", 0) or 0)
    parts = []
    if shot_no == 1 or shot_start == 0:  # 首镜无时间戳（官方 §5.1）
        parts.append(f"[Shot {shot_no}] {scene_desc()}.")
    else:
        parts.append(f"[Shot {shot_no}] At {_fmt_timestamp(shot_start)}, the shot cuts to {scene_desc()}.")
    for t in tags:
        if t.get("kind") != "scene":
            parts.append(f"{t['subject']} appears as {t['name']}.")
    if v.get("camera"):
        parts.append(f"The camera: {v['camera']}.")
    if v.get("action"):
        parts.append(f"Action/event: {v['action']}.")
    if v.get("lighting"):
        parts.append(f"Lighting/tone: {v['lighting']}.")
    dialogue = shot.get("dialogue") or []
    spk = list(speaker_ids or range(1, len(dialogue) + 1))
    for d, sid in zip(dialogue, spk):
        text = _clean_dialogue(d.get("text", ""))
        parts.append(f"A speaker (S{sid}) says: <d>[{_detect_lang(text)}] {text}</d>")
    if no_sub:
        parts.append("The frame shows no subtitles, text, titles, watermarks, or decorative captions.")
    lines.append(opener + " " + " ".join(parts))
```

- **首镜判断** `shot_no == 1 or shot_start == 0`：首镜头或 0 秒开始不写时间戳。若你的分镜表首镜 start 非 0（从中间切），此规则会写时间戳——按需调整。
- **新增画面字段**（道具/服装/情绪）：在 lighting 后加 `if v.get("props"): parts.append(f"Props: {...}.")`，storyboard 字段名要对上。
- **多条台词**逐条成句（不再拼接）；`speaker_ids` 由 build_h3_pack 全局分配。
- `no_sub` 分支控制字幕禁令；想看字幕在 config 改 `audio_text_policy` 即可。
- 想改对白句式（如加 `<scenetrans>` 跨镜处理）在此循环扩展。

**第 5、6 段 sound/music**（225-234 行）：

```python

    lines.append("N/A" if not dialogue else "Ambient sound focuses on dialogue with slight spatial reverb.")
    lines.append("non_diegetic_music:")
    music = v.get("music_note") or ""
```

- 两段仍是占位策略（无音频分析模块）；roadmap 落地音频分析后改为读音频字段。

3. 需 stage2 ASR 支持 speaker 分离才能可靠判定（当前为近似）。
