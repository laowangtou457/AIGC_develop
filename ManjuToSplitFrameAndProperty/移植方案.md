# 工程移植方案（ManjuToSplitFrameAndProperty）

把工程从本机（A 机）移植到另一台电脑（B 机）的完整操作手册。
适用场景：新电脑继续做视频拆解/H3 提示词；B 机可以是 Windows 或 Linux（步骤基本一致，命令换 shell）。

---

## 一、总体原则（先说结论）

| 东西 | 拷不拷 | 原因 |
|---|---|---|
| 源码 + 配置 + 文档（pipeline/tools/docs/schemas/samples/config.yaml/requirements.txt） | ✅ 拷 | 无本地绝对路径依赖 |
| `.venv\` 虚拟环境 | ❌ 绝不拷 | pyvenv.cfg 写死本机 Python 路径，且含平台二进制，拷过去必坏 |
| `output\` 历史产物 | ⭕ 可选 | 你以前跑出来的 37集 等，拷不拷都不影响运行 |
| faster-whisper 模型 | ⭕ 首次自动下载 | B 机跑阶段2 时联网拉取（约 75MB） |
| 人脸 Haar 模型 | ✅ 随 opencv 包 | 无需手动处理 |
| ffmpeg | ✅ 随 imageio-ffmpeg 包 | 无需手动处理 |
| Ollama + qwen2.5vl:3b（本地 VLM） | ❌ B 机另装 | 不装则画面描述为空（不报错，可后续补） |

**一句话：拷"包"（脚本已打包好），不拷"环境"（环境在 B 机重建）。**

---

## 二、操作步骤

### 第 1 步：A 机打包（已内置脚本，一键执行）

```powershell
cd D:\AIGC\develop\New_AI_Production_Workflow\ManjuToSplitFrameAndProperty
powershell -ExecutionPolicy Bypass -File .\deploy\export_package.ps1
```

产物：
- `D:\AIGC\ManjuToSplitFrameAndProperty_package\`（解包目录）
- `D:\AIGC\ManjuToSplitFrameAndProperty_package.zip`（约 1-2 MB）

打包内容：pipeline、tools、docs、schemas、samples、workflows、comfyui、config.yaml、README.md、requirements.txt、run_all.py
自动排除：`.venv`、`output`、`__pycache__`、`*.pyc`

### 第 2 步：拷贝到 B 机

U 盘 / 网盘 / 局域网任选，把 zip 拷过去解压到目标目录（如 `D:\AIGC\New_AI_Production_Workflow`）。

### 第 3 步：B 机装 Python 3.12

- 官网下载：https://www.python.org/downloads/
- 安装时**勾选 "Add python.exe to PATH"**
- 验证：`python --version` 显示 3.12.x

### 第 4 步：B 机一键部署（已内置脚本）

```powershell
cd <解压后的工程目录>
powershell -ExecutionPolicy Bypass -File .\deploy\setup_new_machine.ps1
```

脚本自动完成：检测 Python → 建 `.venv` → `pip install -r requirements.txt`（需联网 2-3 分钟）→ 跑 sample_12s.mp4 阶段1 冒烟测试 → 提示 Ollama 可选装。

### 第 5 步：验证 + 正式跑

```powershell
# 冒烟（全流程，用自带 12 秒示例）
.\.venv\Scripts\python run_all.py samples\sample_12s.mp4 --platform minimax_h3

# 正式（自己的视频）
.\.venv\Scripts\python run_all.py <你的视频.mp4> --platform minimax_h3
```

## 三、B 机要不要装本地 VLM（可选）

- **不装**：config.yaml 里 `vlm_provider: openai` + `vlm_base_url: http://localhost:11434/v1` 会连不上 → 阶段2 静默跳过视觉描述（提示词里场景为"（场景待补充）"）。想先跑通就把 config 里这两行改回：
  ```yaml
  vlm_provider: ""       # 关闭视觉理解
  vlm_base_url: ""
  ```
- **要装**（推荐，描述质量差异大）：B 机装 Ollama + 拉模型，复用 `D:\AIGC\local_vlm\` 目录下的安装包和 README：
  1. 安装 `OllamaSetup.exe`（可把 A 机 `D:\AIGC\local_vlm\downloads\` 里的安装包拷过去）
  2. 设置模型目录：`[Environment]::SetEnvironmentVariable('OLLAMA_MODELS', '<B机路径>\models', 'User')`
  3. `ollama pull qwen2.5vl:3b`（3.2GB）
  4. 若 B 机 GPU 是 NVIDIA 且驱动较新（≥580）可满血 CUDA；老驱动（如 560）跑不了 Ollama 自带 CUDA 运行时，把 `lib\ollama\cuda_v12`、`cuda_v13` 目录移走即可自动回退 Vulkan+CPU（详见 `D:\AIGC\local_vlm\README.md`）
  5. config.yaml 保持 `vlm_provider: openai` + `vlm_base_url: http://localhost:11434/v1`

## 四、常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| `No module named ...` | venv 没建或依赖没装 | 重跑 setup_new_machine.ps1 |
| 阶段1 报 ffmpeg 找不到 | 依赖未装全 | 确认 imageio-ffmpeg 已装（requirements 里有） |
| 阶段2 卡在下载模型 | faster-whisper 首次联网拉模型 | 等它下完；离线环境需手动拷贝 `~\.cache\huggingface\` 下 whisper 缓存 |
| 中文路径视频/目录读图失败 | OpenCV 中文路径 bug | 本工程已内置 `imread_unicode/imwrite_unicode` 修复，无需处理 |
| VLM 描述全空 | Ollama 未装/未启动 | 见第三节；或临时关闭 VLM |
| 运行报 `Permission denied` | 新机权限 | 用普通用户权限目录即可，勿放 C 盘 Program Files |
