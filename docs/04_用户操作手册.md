## 一、这是什么

本系统把一部小说自动变成"分镜脚本 + 逐镜提示词 + 分镜图 + 视频"的完整生产线：

```
导入小说 ─→ 生成剧本 ─→ 编辑章节 ─→ 生成文字分镜 ─→ 生成分镜提示词 ─→ 生成视频
                │              │            │                │
                │              └── 并行区间（与主流程同步）──┘
                │    AI解析角色 ─→ 生成角色图（素材注入）
                │    AI解析场景 ─→ 生成场景图（素材注入）
                │    AI解析道具 ─→ 生成道具图（素材注入）
                └──────────────────────────────► 角色/场景/道具素材 ──► 生成视频
```

**核心特色（本版本新增）**：分镜与提示词由 **H3 漫剧引擎** 生成——按专业漫剧导演规则（节拍分析、运镜、景别、情绪外化、边界锁）自动拆解镜头，并为每个镜头产出符合 MiniMax H3 视频模型的提示词。

## 二、开始之前（5 分钟准备）

### 1. 启动后端服务（终端窗口 1）

> 📌 以下命令同时给出「命令提示符 cmd」和「PowerShell」两种写法，按你打开的窗口类型任选其一。

**方式 A：命令提示符（cmd）**
```bat
cd /d D:\AIGC\develop\New_AI_Production_Workflow\AI-NovelFlow\backend
C:\Users\ghgh\AppData\Local\Programs\Python\Python312\python.exe -m uvicorn app.main:app --host 0.0.0.0 --port 8000
```

**方式 B：PowerShell**
```powershell
Set-Location D:\AIGC\develop\New_AI_Production_Workflow\AI-NovelFlow\backend
C:\Users\ghgh\AppData\Local\Programs\Python\Python312\python.exe -m uvicorn app.main:app --host 0.0.0.0 --port 8000
```

看到 `Uvicorn running on http://0.0.0.0:8000` 即成功。

> ⚠️ 若提示 `address already in use` / `[Errno 10048]`：说明 8000 端口已被占用（服务可能已在运行，或残留进程未退出）。先执行下面的「停止旧服务」，再重新启动。

**停止旧服务（仅在端口被占用时使用）**
```bat
netstat -ano | findstr :8000
taskkill /F /PID <上面查到的PID>
```
PowerShell 写法：
```powershell
Get-NetTCPConnection -LocalPort 8000 | Select-Object LocalAddress,OwningProcess
Stop-Process -Id <上面查到的PID> -Force
```

### 2. 启动前端界面（终端窗口 2）

**方式 A：命令提示符（cmd）**
```bat
cd /d D:\AIGC\develop\New_AI_Production_Workflow\AI-NovelFlow\frontend\my-app
npm run dev
```

**方式 B：PowerShell**
```powershell
Set-Location D:\AIGC\develop\New_AI_Production_Workflow\AI-NovelFlow\frontend\my-app
npm run dev
```

看到 `Local: http://localhost:5173/` 后，用浏览器打开 **http://localhost:5173**。

> ⚠️ 若提示 `Port 5173 is in use`：5173 被占用，同样先停掉旧前端进程（查 5173 端口对应的 PID 后 kill）再启动。

### 3. 配置 LLM（重要！否则无法生成）

1. 进入首页 → 右上角「系统设置」
2. 填好以下三项后保存：
   - **LLM 供应商**：DeepSeek（或你已有的服务商）
   - **API URL**：`https://api.deepseek.com`（按供应商填写）
   - **API Key**：你的密钥（这是关键，当前数据库里此项为空）
3. 保存后回到首页，看到「DeepSeek 连接成功」即可

### 4. （可选）启动 ComfyUI 用于出图/出视频

如需生成分镜图与视频，保持 ComfyUI 运行在 `http://127.0.0.1:8188`。仅做文字分镜/提示词不需要。

## 三、完整操作流程

### 第 1 步：导入小说

1. 首页点击「导入小说」或左侧「小说管理」
2. 新建小说：填写 **标题**、**作者**、**简介**
3. 创建后进入小说详情

> 💡 也可以批量导入：章节管理 → 批量导入（支持整本小说文本，自动分章）。

### 第 2 步：生成剧本 / 编辑章节

1. 进入小说 → 「章节管理」
2. 新增章节（填章回名），把**剧本或小说正文**粘贴到「原文内容」
3. 保存

> 章节正文就是 H3 分镜的输入。内容越完整（对白、动作、场景描述），分镜质量越高。

### 第 3 步：H3 生成文字分镜（核心新增功能）

1. 进入章节 → 顶部 Tab 选择「**分镜拆分**」
2. 点击紫色按钮「**H3 生成文字分镜**」
3. 弹出确认框（提示将清空当前分镜）→ 点「确定」
4. 等待生成（约 30-90 秒，视章节长度与网络而定）
5. 生成成功后，左侧列表出现该章所有镜头，右侧可逐镜查看/编辑：

| 分镜字段 | 含义 | 示例 |
|---|---|---|
| 序号 | 镜头编号 | 镜 1 |
| 场景 | 本镜发生地 | 森林 |
| 角色 | 出场的角色 | 小红帽、大灰狼 |
| 动作 | 画面内容 | 小红帽蹲下采花，狼从树后探头 |
| 运镜 | 镜头运动 | 从全景缓慢推近 |
| 景别 | 取景大小 | 中近景 |
| 情绪 | 氛围基调 | 紧张 |
| 时长 | 镜头秒数 | 4 秒 |
| 台词 | 本镜对白 | "小姑娘，你要去哪儿呀？" |

### 第 4 步：H3 生成分镜提示词（核心新增功能）

1. 确认第 3 步已生成分镜
2. 点击紫红色按钮「**生成分镜提示词（H3）**」
3. 等待逐镜生成（每镜一次 LLM 调用，镜头多时耐心等待）
4. 完成后，每个分镜的「视频描述」中就是该镜的 **H3 提示词**（供第 7 步视频生成使用）

> 提示词含 `<Subject>`、`<Picture>`、`<Audio>` 等专业标签，这是 MiniMax H3 模型的官方输入格式，无需手动修改。

### 第 5 步：并行生成角色 / 场景 / 道具图（素材准备）

在主流程进行的同时，可以并行准备视频素材：

1. **角色图**：角色管理 → 选择角色 → 「AI 解析外观」→「生成角色图」
2. **场景图**：场景管理 → 选择场景 → 「生成场景图」
3. **道具图**：道具管理 → 选择道具 → 「生成道具图」

这些图会在生成视频时作为参考素材（`<Picture N>`）注入。

> 提示：H3 分镜生成时会自动从章节提取角色/场景/道具清单（存于章节资源），可点击「📦 章节资源」查看。

### 第 6 步：生成分镜图（可选但推荐）

1. 进入「分镜图生成」Tab
2. 选择镜头，点击「生成」→ 等待出图
3. 每镜可生成独立分镜图，用于检查构图

### 第 7 步：生成视频

1. 进入「视频生成」Tab
2. 确认该镜已有 H3 提示词（第 4 步产物）
3. 选择生成模式（默认即可；如已在第 5 步准备好角色图，选择带参考图的模式）
4. 点击「生成」→ 等待渲染（较耗时）

### 第 8 步：导出与合片

- 「📥 导出分镜」：导出分镜表
- 「下载素材」：打包下载该章所有图片/视频素材
- 「合并视频」：把多镜视频自动拼接成完整成片

## 五、概念速查表

| 名词 | 说明 |
|---|---|
| **分镜（Shot）** | 一个镜头：一段连续拍摄的画面，含场景/角色/动作/时长/台词 |
| **文字分镜** | 用文字描述每个镜头该拍什么（H3 引擎自动生成） |
| **H3 提示词** | 喂给 MiniMax H3 视频模型的官方格式提示词，含 `<Subject>`/`<Picture>`/`<Audio>` 标签与时间轴对齐说明 |
| **资源映射** | 「角色A=图1」的对应关系，告诉模型"图1 是角色A 的参考形象" |
| **素材注入** | 把角色/场景/道具图作为参考图注入视频生成过程，保证人物/场景一致 |
| **视频导演模式** | 系统按镜头时长自动规划关键帧、运镜、转场的高级模式 |
| **边界锁（continuity）** | H3 分镜里对人物位置/姿态/道具归属的连续约束，保证前后镜头不穿帮 |
| **`<Picture N>`** | H3 提示词中的参考图占位标签，N 为图序号 |

## 六、常见问题 FAQ

### Q0：按手册启动后端/前端直接报错怎么办？

分两种情况：

**① PowerShell 里执行 `cd /d ...` 报错（`Set-Location : 找不到接受实际参数...`）**
**原因**：`cd /d` 是「命令提示符 cmd」的语法，PowerShell 不支持。
**解决**：PowerShell 用 `Set-Location 路径`（即 `cd 路径`，不带 /d），详见「二、开始之前」的两种写法；或直接改用 cmd 窗口执行。

**② 报 `address already in use` / `[Errno 10048]` / `Port 5173 is in use`**
**原因**：端口已被占用——服务可能已在运行，或上次启动的进程没有退出。
**解决**：查端口占用并停掉旧进程后重启（命令见「二、开始之前」）；若浏览器里页面正常打开，说明服务其实已就绪，无需重复启动。

### Q1：点击 H3 按钮后提示「LLM API Key 未配置」/ 401 认证失败

**原因**：系统设置里的 LLM API Key 为空或无效。
**解决**：进入首页「系统设置」→ 填写正确的 API Key → 保存 → 重试。

### Q2：提示「该章节尚未生成 H3 分镜，请先执行生成文字分镜」

**原因**：点「生成分镜提示词」前没有先生成文字分镜。
**解决**：先点紫色「H3 生成文字分镜」，成功后再生成提示词。

### Q3：分镜生成为空 / 提示「JSON 解析失败」

**原因**：LLM 输出异常（偶发）或章节内容过短。
**解决**：
- 再次点击重试（LLM 偶发波动）
- 增加章节正文长度与细节（对白/动作/场景）
- 检查网络与 API 配额

### Q4：分镜数量或时长不符合预期

**说明**：H3 引擎按剧本节拍自动拆分，单镜 2-5 秒，整章时长由内容量决定。
**解决**：生成后可在分镜列表逐个微调（时长、动作、台词），或「编辑结构数据」批量调整。

### Q5：ComfyUI 连接失败（首页显示）

**原因**：ComfyUI 未启动，或端口不是 8188。
**解决**：启动 ComfyUI（见二.4）；仅做文字分镜/提示词可忽略此项。

### Q6：视频生成很慢或失败

**说明**：视频渲染依赖 GPU（当前 1050 Ti 无法运行 MiniMax-H3 模型，需 RTX 30 系+ 显卡）。
**解决**：
- 确认 ComfyUI 已启动且模型已加载
- 换装更高性能显卡后重试
- 先用「生成视频」的单镜模式小范围验证

### Q7：如何重做某个步骤？

- 重新生成分镜：再点「H3 生成文字分镜」（会清空当前分镜与已生成资源，有确认提示）
- 只重生成提示词：再点「生成分镜提示词（H3）」（覆盖各镜视频描述）
- 单个分镜：在列表中选中后编辑保存

### Q8：H3 提示词里没有参考图标签（`<Picture>`）？

**说明**：未提供资源映射时，提示词不含参考图标签，视频将按文字描述生成。
**解决**：使用第 5 步生成的角色/场景/道具图，并在视频生成时选择带参考图的模式（后续版本会提供图形化映射界面）。

## 七、使用技巧与注意事项

### 让分镜质量更高的技巧

1. **剧本写清"三要素"**：谁（角色）、在哪（场景）、做什么/说什么（动作+对白）
2. **对白逐字保留**：台词会被原样放进分镜与配音
3. **每章 500-1500 字为宜**：过长可拆多章，过短分镜会偏少
4. **风格预设**：后续版本会在分镜页开放风格/画幅/时长预设选择（古风/都市/校园/科幻等）

### 注意事项

- ⚠️ 重新生成分镜会**清空已生成的分镜图/视频**，重要成果请先「导出分镜」或下载素材
- ⚠️ H3 提示词生成按镜头逐个调用 LLM，镜头多时请耐心等待，勿重复点击
- ℹ️ 原「✨ AI 拆分」保留可用，两种引擎结果可对比选择
- ℹ️ 本手册对应版本：H3 漫剧工作流集成 v1.0（2026-09-17）
