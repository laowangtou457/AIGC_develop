## 一、这是什么

本系统把"小说 / 一句话需求 / 参考成片"三类输入，自动变成"分镜 + 提示词 + 图像 + 视频"的完整生产线，共三条工作流：

| 工作流 | 输入 | 输出 |
|---|---|---|
| ① 小说生成视频 | 小说文本 | 分镜脚本、H3 提示词、关键帧、配音、成片 |
| ② AI 武术指导 | 一句话需求（+参考图） | 16 宫格分镜、角色形象图、武打视频 |
| ③ 视频资源替换 | 参考成片 | 切镜/台词/资产、多平台提示词、替换后成片 |

**核心特色**：
- 分镜与提示词由 **H3 漫剧引擎** 生成（专业漫剧导演规则），输出兼容 Seedance / Kling / Veo / 即梦 / 海螺的提示词
- 全部能力本地运行（Ollama + ComfyUI），数据不出本机

## 二、开始之前（5 分钟准备）

### 1. 一键启动（推荐）

双击工程根目录 `一键启动全家桶.bat`，自动拉起 4 个服务并健康检查：

| 服务 | 端口 | 用途 |
|---|---|---|
| Ollama | 11434 | 本地 LLM / VLM |
| ComfyUI | 8188 | 生图 / 生视频 |
| 后端 | 8000 | 平台 API |
| 前端 | 5173 | 浏览器访问 http://localhost:5173 |

### 2. 手动启动（调试用）

```bat
:: 后端
cd /d F:\Develop\NewAIProductionWorkflow\AI-NovelFlow\backend
venv\Scripts\python -m uvicorn app.main:app --host 0.0.0.0 --port 8000

:: 前端
cd /d F:\Develop\NewAIProductionWorkflow\AI-NovelFlow\frontend\my-app
npm run dev
```

### 3. 系统设置（首次必配）

1. 进入首页 → 右上角「系统设置」
2. **LLM 供应商**：选 `Ollama`；**API URL**：`http://127.0.0.1:11434/v1`
3. 保存后回到首页，确认 Ollama 连接正常
4. 生图/生视频由 ComfyUI 执行，保持 :8188 运行即可

## 三、工作流①：小说生成视频

### 完整流程

```
导入小说 → AI解析角色/场景/道具 → 编辑章节 → H3生成文字分镜 → 生成分镜提示词(H3)
                                              │
            并行：AI解析角色/场景/道具 → 生成对应图（素材注入）
                                              │
                  生成主分镜图/关键帧 → 音频/台词合成 → 视频生成 → Shot合并 → 章节成片
```

### 分步操作

| 步骤 | 操作 | 说明 |
|---|---|---|
| 1 导入小说 | 首页「导入小说」或「小说管理」 | 填标题/作者/简介；也可批量导入整本 TXT |
| 2 解析资产 | 章节管理 → 解析角色/场景/道具 | 自动提取并生成对应图片；角色自动去重（同人同年龄段唯一） |
| 3 编辑章节 | 章节详情 → 粘贴正文/剧本 | 内容越完整（对白/动作/场景）分镜质量越高 |
| 4 H3 文字分镜 | 分镜拆分 →「H3 生成文字分镜」 | 按导演规则拆镜头（30b 模型，约 30-90 秒） |
| 5 分镜提示词 | 分镜拆分 →「生成分镜提示词（H3）」 | 逐镜生成六段式提示词，写入「视频描述」 |
| 6 分镜图/关键帧 | 分镜图生成 Tab | 生成主分镜图；超长镜头自动规划多关键帧 |
| 7 音频 | 音频生成 Tab | 按台词生成角色配音/旁白 |
| 8 视频 | 视频生成 Tab →「生成」 | 首尾帧/多关键帧模式；单段 ≤15s，超长自动补帧 |
| 9 合片 | 「合并视频」/ 最终视频页 | 多镜拼接成章节成片 |

### 提示

- 每个角色/场景/道具都有「AI 重新生成提示词」按钮；外观描述保存后自动转英文
- ⚠️ 重新生成分镜会清空已生成的分镜图/视频，重要成果先导出

## 四、工作流②：AI 武术指导并生成视频

入口：侧边栏「武术指导」（/martial-arts）

### 流程

```
一句话需求（+参考图） → 需求解析 → 人物锚定卡 → 16宫格分镜提示词
  → ① 角色形象图 → ② 分镜图 → ③ 武打视频
```

### 分步操作

| 步骤 | 操作 | 说明 |
|---|---|---|
| 1 输入需求 | 一句话描述（如"太极宗师对外家拳师，晨曦庭院，要有太极哲学"） | 可上传参考图，由视觉模型解析生成资产 |
| 2 生成锚定卡 | 点击生成 | 多角色定义（性别/年龄/服装/武器/形象细节，英文） |
| 3 16 宫格分镜 | 生成武打分镜提示词 | 16 个独立镜头块，递增时间戳、动作不重复、机位逐镜变化 |
| 4 角色形象图 | 「生成角色形象图」 | 文生图（Flux2-4B），锁定人物形象 |
| 5 分镜图 | 「生成分镜图」 | 图生图（以形象图为参考），16 宫格海报 |
| 6 武打视频 | 「生成武打视频」 | 单段 15s，自动分段拼接 30/45/60s 成片 |

### 提示

- 历史任务自动保存（角色/分镜图/视频/时间），刷新不丢，可随时回看
- 需求里**人物数量**写清楚（"两人对打"等），提示词会约束画面人物一致

## 五、工作流③：视频导入解析替换资产并生成视频

入口：侧边栏「视频资源替换」（/video-asset-swap）

### 流程

```
上传参考成片 → 自动分析（数分钟） → 浏览分镜/关键帧/台词/资产
  → 替换角色/场景资产（原创形象） → 重新导出提示词 → 下载提示词包
```

### 分步操作

| 步骤 | 操作 | 说明 |
|---|---|---|
| 1 上传 | 点击上传（mp4/mov/mkv 等） | 后台自动跑管线：切镜+ASR+VLM+资产抽取 |
| 2 浏览 | 任务列表 → 详情 | 分镜时间线+关键帧网格 / 分镜表 / 资产卡片 / H3 提示词 |
| 3 替换资产 | 资产卡片 →「替换资产」 | 上传无版权原创形象图，原图自动备份，重跑导出 |
| 4 下载 | 「下载 ZIP」 | 提示词包含逐镜提示词 + payload（可直接粘贴 Seedance/Kling/Veo/即梦/海螺） |
| 5 提交生成 | 海螺/API 提交 | 得到"剧情/台词/音乐与原片接近，人物/场景/服装已替换"的成片 |

### 合规自检（每次发布前）

- 输入视频为自有 / 已授权 / 公有领域内容
- 剧情、台词、音乐已实质性改写
- 人物形象已替换为无版权问题形象（原创/授权/自扫描）
- 生成结果仅用于个人学习或非盈利展示

## 七、常见问题 FAQ

### Q1：提示「ComfyUI 连接失败」/ 生图不动

- 确认一键启动已拉起 ComfyUI（:8188）；页面「系统配置-ComfyUI 工作流」映射完整
- 显存占满时任务会排队（GPU 串行调度），属正常现象，等队列消化

### Q2：H3 生成文字分镜报「拆分失败，请检查网络连接」

- 确认 Ollama 运行（`ollama list`）；系统设置 LLM 选 Ollama 且 URL 正确
- 分镜用 30b 模型，若显存紧张会排队，耐心等待

### Q3：分镜提示词是空的 / 只有文字没有参考图标签

- 先生成文字分镜，再生成提示词（有依赖顺序）
- 未提供资源映射时提示词无 `<Picture>` 标签，视频按文字描述生成

### Q4：视频生成失败 / 15 秒超限

- 单段 15s 是模型上限；超长镜头请用多关键帧模式或分段拼接
- 失败后按提示"重新生成缺失 Clip 或重新生成当前 Shot 视频"

### Q5：生成的角色不像 / 动作崩坏

- 角色：编辑外观描述 → 点「AI 重新生成提示词」（英文）→ 重新生成图
- 动作：细化视频提示词（写清每个分镜动作、机位）；或换 45/60s 分段拼接

### Q6：视频资源替换的分析结果没有画面描述

- 画面描述依赖 VLM（qwen2.5vl）；Ollama 未启动时降级为"待补充"，不阻断其他步骤
