一、这是什么

本系统把一部小说自动变成「分镜脚本 + 逐镜提示词 + 分镜图 + 视频」的完整生产线。分镜与提示词由 H3 漫剧引擎 按专业导演规则自动生成（节拍分析、运镜、景别、情绪外化、边界锁），提示词为 MiniMax H3 视频模型官方格式，可直接用于出视频。

二、开始之前（5 分钟准备）

1️⃣ 启动后端服务（终端窗口 1）

📌 按窗口类型二选一：cmd（命令提示符） 或 PowerShell

方式 A：命令提示符（cmd）

cd /d D:\AIGC\develop\New_AI_Production_Workflow\AI-NovelFlow\backend
C:\Users\ghgh\AppData\Local\Programs\Python\Python312\python.exe -m uvicorn app.main:app --host 0.0.0.0 --port 8000

方式 B：PowerShell

Set-Location D:\AIGC\develop\New_AI_Production_Workflow\AI-NovelFlow\backend
C:\Users\ghgh\AppData\Local\Programs\Python\Python312\python.exe -m uvicorn app.main:app --host 0.0.0.0 --port 8000

看到 Uvicorn running on http://0.0.0.0:8000 即成功。

⚠️ 若报 address already in use / [Errno 10048]：8000 被占用（服务已在运行或旧进程未退出）。先查并停止旧进程再启动：
cmd：netstat -ano | findstr :8000 → taskkill /F /PID <PID>
PowerShell：Get-NetTCPConnection -LocalPort 8000 | Select OwningProcess → Stop-Process -Id <PID> -Force

2️⃣ 启动前端界面（终端窗口 2）

方式 A：命令提示符（cmd）

cd /d D:\AIGC\develop\New_AI_Production_Workflow\AI-NovelFlow\frontend\my-app
npm run dev

方式 B：PowerShell

Set-Location D:\AIGC\develop\New_AI_Production_Workflow\AI-NovelFlow\frontend\my-app
npm run dev

看到 Local: http://localhost:5173/ 后，浏览器打开 http://localhost:5173

⚠️ 若提示 Port 5173 is in use：5173 被占用，查 5173 端口 PID 后 kill 再启动（命令同上，把端口换成 5173）。

3️⃣ 配置 LLM（重要！否则无法生成分镜/提示词）

  1. 首页右上角进入「系统设置」
  2. 填写：LLM 供应商（DeepSeek）、API URL（https://api.deepseek.com）、API Key（你的密钥，当前为空）
  3. 保存后回首页确认「DeepSeek 连接成功」

4️⃣ （可选）启动 ComfyUI 用于出图/出视频

保持 ComfyUI 运行在 http://127.0.0.1:8188。仅做文字分镜/提示词不需要。

三、完整操作流程

1

导入小说

首页「导入小说」→ 新建：填写标题 / 作者 / 简介 → 进入小说详情。

💡 章节管理支持「批量导入」：粘贴整本小说文本，自动分章。

2

生成剧本 / 编辑章节

小说 →「章节管理」→ 新增章节 → 把剧本或小说正文粘贴到「原文内容」→ 保存。

⚠️ 章节正文就是 H3 分镜的输入，内容越完整（对白/动作/场景），分镜质量越高。

3

H3 生成文字分镜 核心新增

  1. 进入章节 → Tab 选「分镜拆分」
  2. 点击紫色按钮「H3 生成文字分镜」→ 确认（将清空当前分镜）→ 等待 30-90 秒
  3. 左侧出现该章所有镜头，右侧可逐镜查看/编辑
分镜字段含义示例
序号镜头编号镜 1
场景本镜发生地森林
角色出场的角色小红帽、大灰狼
动作画面内容小红帽蹲下采花，狼从树后探头
运镜 / 景别 / 情绪镜头运动 / 取景大小 / 氛围从全景缓慢推近 / 中近景 / 紧张
时长镜头秒数4 秒
台词本镜对白"小姑娘，你要去哪儿呀？"
4

H3 生成分镜提示词 核心新增

  1. 确认第 3 步已生成分镜
  2. 点击紫红色按钮「生成分镜提示词（H3）」→ 等待逐镜生成
  3. 完成后每个分镜的「视频描述」即为该镜 H3 提示词（含 <Subject>/<Picture>/<Audio> 等官方标签，无需手动修改）
5

并行生成角色 / 场景 / 道具图（素材准备）

  1. 角色图：角色管理 → 选角色 →「AI 解析外观」→「生成角色图」
  2. 场景图：场景管理 → 选场景 →「生成场景图」
  3. 道具图：道具管理 → 选道具 →「生成道具图」

💡 H3 分镜会自动从章节提取角色/场景/道具清单，点「📦 章节资源」可查看与跳转。

6

生成分镜图（可选但推荐）

「分镜图生成」Tab → 选镜头 →「生成」→ 检查构图。

7

生成视频

「视频生成」Tab → 确认已有 H3 提示词 → 选模式（有角色图时选带参考图模式）→「生成」→ 等待渲染。

8

导出与合片

  • 「📥 导出分镜」：导出分镜表
  • 「下载素材」：打包下载本章全部图片/视频素材
  • 「合并视频」：多镜视频自动拼接成完整成片

六、常见问题 FAQ

Q0：按手册启动后端/前端直接报错怎么办？

① PowerShell 里执行 cd /d ... 报错（Set-Location : 找不到接受实际参数...）
原因：cd /d 是 cmd 语法，PowerShell 不支持。
解决：PowerShell 用 Set-Location 路径（不带 /d），见「二、开始之前」两种写法；或直接改用 cmd 窗口执行。

② 报 address already in use / [Errno 10048] / Port 5173 is in use
原因：端口已被占用——服务可能已在运行，或上次启动的进程未退出。
解决：查端口占用并停掉旧进程后重启（命令见「二、开始之前」）；若浏览器页面能正常打开，说明服务已就绪，无需重复启动。

Q1：提示「LLM API Key 未配置」/ 401 认证失败

原因：系统设置里的 LLM API Key 为空或无效。
解决：首页「系统设置」→ 填写正确 API Key → 保存 → 重试。

Q2：提示「该章节尚未生成 H3 分镜，请先执行生成文字分镜」

原因：没先生成文字分镜就直接生成提示词。
解决：先点紫色「H3 生成文字分镜」，成功后再生成提示词。

Q3：分镜生成为空 / 提示「JSON 解析失败」

原因：LLM 输出偶发异常，或章节内容过短。
解决：① 重试一次；② 增加章节正文细节（对白/动作/场景）；③ 检查网络与 API 配额。

Q4：分镜数量或时长不符合预期

H3 引擎按剧本节拍自动拆分（单镜 2-5 秒）。生成后可在列表逐个微调（时长/动作/台词），或「编辑结构数据」批量调整。

Q5：ComfyUI 连接失败（首页显示）

ComfyUI 未启动或端口不是 8188。启动 ComfyUI 即可；仅做文字分镜/提示词可忽略。

Q6：视频生成很慢或失败

视频渲染依赖 GPU（当前 1050 Ti 无法运行 MiniMax-H3，需 RTX 30 系+）。确认 ComfyUI 已启动、模型已加载；换装更高性能显卡后重试；可先用单镜模式小范围验证。

Q7：如何重做某个步骤？

重新生成分镜：再点「H3 生成文字分镜」（清空旧分镜与资源，有确认提示）；只重生成提示词：再点「生成分镜提示词（H3）」；单个分镜：选中后编辑保存。

Q8：H3 提示词里没有 <Picture> 参考图标签？

未提供资源映射时不生成参考图标签，视频按文字描述生成。使用第 5 步的角色/场景/道具图，并在视频生成时选择带参考图的模式。

七、使用技巧与注意事项

让分镜质量更高的技巧

  • 剧本写清三要素：谁（角色）、在哪（场景）、做什么/说什么（动作+对白）
  • 对白逐字保留：台词会原样放进分镜与配音
  • 每章 500-1500 字为宜：过长可拆多章，过短分镜偏少

注意事项

  • ⚠️ 重新生成分镜会清空已生成的分镜图/视频，重要成果先「导出分镜」或下载素材
  • ⚠️ H3 提示词按镜头逐个调用 LLM，镜头多时耐心等待，勿重复点击
  • ℹ️ 原「✨ AI 拆分」保留可用，两种引擎结果可对比
