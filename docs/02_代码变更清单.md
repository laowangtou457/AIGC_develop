## 2. 新增：H3ManjuService 服务

**路径**：`backend/app/services/h3_manju_service.py`
**修改目的**：封装 H3 漫剧业务能力（剧本→分镜、分镜→逐镜提示词），LLM 调用复用系统配置，供 API 层调用。

### 核心代码

```python
class H3ManjuService:
    """H3 漫剧分镜服务：剧本→分镜剧本→逐镜 H3 提示词。"""

    def __init__(self, llm_service: Optional[LLMService] = None):
        self.llm = llm_service or LLMService()

    async def _chat(self, system_prompt, user_content, temperature=0.2, max_tokens=32768) -> str:
        """调用 AI-NovelFlow LLM，返回文本（复用系统设置中的 LLM 配置）。"""
        result = await self.llm.chat_completion(
            system_prompt=system_prompt,
            user_content=user_content,
            temperature=temperature,
            max_tokens=max_tokens,
        )
        if not result.get("success"):
            raise RuntimeError(result.get("error") or "LLM 调用失败")
        content = (result.get("content") or "").strip()
        if not content:
            raise RuntimeError("LLM 返回为空")
        return content

    async def script_to_storyboard(self, script: str, preset_json: str = "") -> Dict[str, Any]:
        """剧本 → 分镜剧本 JSON + 资源清单 JSON + 摘要。"""
        # 1) 组装 system prompt：读取 rules/manju_storyboard.txt
        system = build_manju_system_prompt("manju_storyboard.txt", "")
        user_msg = ("【本集预设】\n" + preset + "\n\n【剧本原文】\n" + script
                    + "\n\n请根据以上剧本与预设生成分镜 JSON（storyboard + assets）。")
        raw = await self._chat(system, user_msg, temperature=0.2)
        # 2) 解析 JSON、补 _policy、校验 shots
        parsed = _extract_json(raw)
        if parsed is None:
            raise ValueError("分镜 JSON 解析失败，请重试。模型输出前 300 字符：%s" % raw[:300])
        storyboard = parsed.get("storyboard", parsed)
        if not isinstance(storyboard, dict) or not storyboard.get("shots"):
            raise ValueError("分镜 JSON 缺少 shots 数组，请重试")
        storyboard["_policy"] = policy
        # 3) 返回 storyboard_json / assets_json / summary
        ...

    async def storyboard_to_shot_prompt(self, storyboard_json, mapping_json, shot_index) -> Dict[str, Any]:
        """分镜 → 该镜 H3 提示词 + 接线说明。"""
        refs = compute_shot_refs(storyboard_json, mapping_json, shot_index)
        wiring = build_wiring_note(storyboard_json, mapping_json, shot_index)
        system = build_manju_system_prompt("manju_shot_prompt.txt", "")
        user_msg = "【本镜数据】\n" + json.dumps(
            {"shot": refs["shot"], "tags": refs["tags"],
             "missing": refs["missing"], "policy": policy}, ensure_ascii=False, indent=2
        ) + "\n\n请按规则生成该镜头的 H3 提示词。"
        prompt = await self._chat(system, user_msg, temperature=0.4)
        return {"h3_prompt": prompt, "wiring_note": wiring, "refs": refs}
```

### 设计说明

- **LLM 单源**：不持有独立密钥，全部走 `LLMService.chat_completion`（读 `system_configs` 表）
- **规则驱动**：system prompt 从 `h3_prompt_builder/rules/*.txt` 读取，与 H3 插件行为一致
- **纯函数复用**：`build_manju_system_prompt` / `_extract_json` / `compute_shot_refs` / `build_wiring_note` / `_policy_from_preset` 均来自 `manju_nodes.py`
- **错误可读**：LLM 失败、JSON 解析失败、缺 shots 均抛出带上下文的 RuntimeError/ValueError，由 API 层转为用户可读 message

### 10.4 显存治理与稳定性

1. **GPU 串行调度**：`gpu_scheduler` 全局锁，同刻单模型任务
2. **Ollama 自动卸载**：ComfyUI 排队时 `keep_alive:0`
3. **视频前 /free**：释放 flux 缓存
4. **解析→卸载→生图串行**：解析类 LLM 与生图不共存
5. **H3 并发 LLM 修复**：两个 LLM 同时调用显存满 → 改串行调度
